# 🗺️ 魔兽世界·无限服全景地图辅助器 (Infinite Atlas v3.0 完整终极版)

## 📦 压缩包文件结构说明
1. **`index.html`（推荐直接打开）**：单文件完整独立版，双击即可在任意浏览器（Chrome / Edge / Firefox / Safari）中直接运行，无需安装任何后端服务或插件。
   ⚠️ 因为底图改成了真实大陆美术，需要同目录下的 **`assets/` 文件夹**，请保持整个目录结构一起拷贝/分享（`file://` 直开即可，无需起服务器）。
2. **`wow_infinite_map_helper.html`**：同 `index.html` 的完整主文件备份。
3. **`css/style.css`**：独立提取的样式表（包含魔兽暗金边框主题、飞艇/轮船/矿道地铁动态流动虚线动画关键帧）。
4. **`js/app.js`**：独立提取的完整地图数据库（50个地图区域、58个跨图连接路口、14条海陆空动态航线、各图鸟点与副本坐标）与交互引擎（全景缩放平移、区域详图下钻、BFS跨大陆智能寻路）。
5. **`assets/kalimdor.png` / `assets/easternkingdoms.png`**：真实魔兽大陆地图底图（卡利姆多 / 东部王国），已按区域轮廓裁剪、去除海面方块。页面加载时由 `MAP_LAYOUT` 常量定位到全景画布上。
6. **`README_艾泽拉斯无限服全地图路口与航线手册.md`**：本离线速查手册。

## 🖼️ 地图素材来源与版权说明

- **底图美术**：`assets/` 下的两张大陆地图来自 Blizzard 官方世界地图美术资源
  （经开源项目 [Sectimus/HighFidelityWorldMap](https://github.com/Sectimus/HighFidelityWorldMap) 的
  `WorldMap/Original/` 分发整理），**版权归 Blizzard Entertainment 所有**，仅用于个人离线查阅，非商业用途。
- **区域边界**：48 个经典老区域的轮廓多边形由 Blizzard 官方区域掩膜（`ZoneMasks` / `ZoneShapes`）
  经 marching squares 提取、与陆地掩膜求交裁剪、Chaikin 平滑后生成，贴合真实海岸线；
  新增的 **河林 / 泽风岛** 两个《无限》新区域，位置由官方客户端 `ZoneShapes.lua` 的
  `UiMapID 2548 / 2521` 坐标换算得到，边界为**示意轮廓**（客户端未提供对应掩膜）。
- 若要商用或再分发，请先取得 Blizzard 与素材整理者的授权。
